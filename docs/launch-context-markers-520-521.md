# Engine launch context and marker repair — #520 / #521

The unreleased successor source repair in [PR #523](https://github.com/git-ksk/reasoning-harness/pull/523) addresses two Engine 0.7.1 launch-relevance regressions: an affirmative fragment could outlive a governing fictional/retracted/false context, and normalization erased the original strikethrough/negation. This concerns source-local relevance/acquisition qualification. It is not proof of external truth or a demonstrated downstream wrong answer.

## Behavior and authority

Only factual excerpt/fact/structured-metadata statements can positively prove the requested launch relation. Title/heading can govern or deny that proof, but cannot supply it. URL/navigation cannot prove or govern it. The original raw statement, question terminator and marker spans are retained before lossy normalization. Markdown strike scope crosses sentence boundaries; open strikes withhold; combining strike and explicit ❌/≠/¬/✗/✘ deny their local claim.

Governing fiction, retraction and explicit falsity are checked across factual/documentary signals before selecting any affirmative fragment. Explicit references to a named different product and clearly separate non-launch properties keep their local scope. Ambiguous context withholds. Neutral multi-sentence prose and legitimate decimal/dotted target/vendor names remain usable.

Positive ownership remains bounded: a canonical name or Harness-declared alias must own a supported affirmative predicate as the subject or direct object in the same statement. A named actor introducing/launching that exact object is supported; documentation and possessive/embedded objects cannot borrow ownership. Supported temporal/documentary adjuncts and non-launch feature questions do not veto a separate affirmative launch. Cross-sentence pronoun resolution, arbitrary paraphrase or model-supplied aliases are outside this local grammar and cannot provide authority. This repair does not claim general natural-language understanding.

Historical v16/v29 and published Engine tags/archives remain immutable. The shared frame helper's extra transition-tail checks apply only to the v17 direct-subject caller. Source attribution/reconciliation, Conflict, citations and trusted human authority are not redefined.
