# Engine 0.7 real-source development measurement v3 (#531)

This is a new measurement, not a rewrite or rerun of v1 or any historical holdout. Both immutable Engine tags run inside the **same actual released CLI0.5.5/provider/runtime host**. It records 24 paired scenarios per provider in two separate tracks, using eight captured official documents from four publisher origin groups. Reused questions, snippets and duplicates are reported separately; these are not24 independent real-world tasks.

Normal track runs the unmodified released `reason` entrypoint with a read-only external resolver. A separate capability for each captured source returns one evidence record, so a rejected scope or synthetic record cannot invalidate an unrelated primary record in the same admission batch. The resolver supplies short authentic excerpts and **host-curated extracted facts/context/scope** reviewed against their captured pages. This measures ordinary CLI planning, acquisition, admission, grounded output and abstention under controlled data. It does not measure raw document extraction, live open-Web search, or production-wide truth. Resolver facts are source-derived evidence inputs; required answer labels and reference review authorization never enter model input. Captured-origin counts come from a separate machine-computed harness-owned manifest, never an external publisher. The three synthetic instruction derivatives retain their factual parent content, distinct derived hashes/URNs and no primary-source admission authority.

Helper track measures actual source-local finalization and opt-in reconciliation with model advice and host-controlled reference review authority. It is not injected into normal CLI. Engine does not authenticate semantic target binding here: six missing-information/wrong-target scenarios deliberately violate or leave unproven the prebinding premise, and count only as diagnostics. The three matched identical-quote wrong-target controls expose that limitation; a source-local quote is never scored as a correct answer to the wrong target. Model equivalence advice cannot grant review authority or promote Known/Supported claims/verification receipts. Identical excerpts skip the adviser; baseline uses zero new-helper calls. Costs are reported as observed.

`corpus.json` retains actual URLs, document hashes, retrieval times, normalized UTF-8 byte spans, quote hashes, curator context, software version metadata, scope and source-derived facts. Full raw/normalized snapshots remain private. Short public quotations total at most25 original words per captured page. The independent reviewer checked all eight hashes/normalizations and18 authentic quotation spans against those private captures before external model calls. Semantic equivalence, source authenticity, review authority and guard eligibility are different axes.

`protocol.json` pins models, seeds, budgets, scheduling, first-observation preservation and gates. `manifest.sha256` freezes the evaluator, data and workflow. Run `run.py --validate-only`, unit tests and `preflight.py --bin-dir ...` before any credential access. `build.py` copies tagged source into scratch space, changes only candidate core and its lock entry, adds an evaluator-only adviser bin, and verifies original CLI main/provider host identity. Normal CLI product source and published tags are unchanged. `--fetch-dependencies` is for credential-free CI dependency setup; source builds are locked/offline.

The single freeze-tag push starts three independent provider lanes after shared preflight. Each lane serializes case/arm invocations, alternates baseline/candidate order, preserves stdout/stderr/traces/resolver request/response journals and durable START/FINISH entries, and never silently reruns a failed semantic observation. Operational failures stay separate from semantic unknowns. The first run can measure a regression or a failure; it must not be overwritten to obtain a pass.

CLI adoption remains **NO-GO** because #520 is still reproducible, the fresh independent set is absent, real same-scope conflicting claims/unknown lineage/corrections are not covered, and usefulness must be demonstrated. This development measurement can guide the next fixes; it cannot close all Phase1 acceptance gates.
